# Spam Email Detection using Machine Learning

## About the Project
This project is about detecting whether a message or email is Spam or Not Spam (Ham).
Nowadays spam messages are very common, so this project helps to understand how
machine learning can be used to classify such messages.

I have implemented this project as a beginner-level machine learning application
to understand text classification.

## Type of Machine Learning
Supervised Learning (Classification)

## Algorithm Used
Naive Bayes (Multinomial Naive Bayes)

## Dataset
I created a small dataset using real-world style messages such as offers,
alerts, OTP messages, and normal personal or official messages.
Each message is labeled as Spam or Ham.

## Tools and Technologies Used
- Python
- Pandas
- Scikit-learn

## How the Project Works
1. The dataset is loaded from a CSV file
2. Text messages are converted into numerical form using CountVectorizer
3. The model is trained using the Naive Bayes algorithm
4. The model predicts whether a message is Spam or Ham
5. The accuracy of the model is displayed

## How to Run the Project
1. Keep spam_detector.py and spam_data.csv in the same folder
2. Run the spam_detector.py file
3. The output will show accuracy and prediction result

## Conclusion
This project helped me understand the basics of text preprocessing,
machine learning classification, and how spam detection systems work.
